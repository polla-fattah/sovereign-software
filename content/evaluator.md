Work through the five steps to assess a piece of software against the [Sovereign Software Evaluation Framework](../methodology/), version 3.0 (proposed). The result is an evidence-led principle profile and a qualified overall determination. There is no numerical score: a verified failure of a fundamental requirement cannot be cancelled by strengths elsewhere, and anything you have not assessed stays not assessed instead of counting as a pass or a failure.

Nothing is saved or sent anywhere. Download a Markdown report or a JSON file when you are done, and import a JSON file later to continue. The framework is a proposed standard, not an accredited certification.
