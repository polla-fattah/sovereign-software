The Sovereign Software Index

Tools that pass the seven gates, grouped by discipline.

These tools were assessed against the seven gates in the manifesto: open, inspectable data formats, full function offline, and the ability to leave without losing anything. The tiers are editorial judgments, not formal audits.

Use the search box and category filters to narrow the list. Every card shows where the tool keeps your data and the command that extracts it.

VCS & Core Tier 1 • Canonical

Git

The archetype of sovereign software. Full commit history lives on your local disk, verified via cryptographic hashes, with 100% offline branching, diffing, and merging.

STORAGE SUBSTRATE:Content-Addressable Merkle DAG (.git)
SYNCHRONIZATION / RUNTIME:Decentralized SSH / HTTPS push-pull
$ git bundle create repo.bundle --all
VCS & Core Tier 2 • Sovereign Core

Jujutsu (jj)

Next-generation version control where even conflicts and rebases are recorded as deterministic, first-class mathematical states in an undoable local operation log. Young project: the storage format is still evolving, so treat it as promising rather than canonical.

STORAGE SUBSTRATE:Append-only Operation Log + Git Backend
SYNCHRONIZATION / RUNTIME:Git-compatible remotes / Native local
$ jj op log --limit 20
VCS & Core Tier 1 • Canonical

SQLite

Library of Congress permanent archival standard. Delivers microsecond local queries with zero server daemons, zero configuration, and guaranteed backward compatibility through 2050.

STORAGE SUBSTRATE:Single Cross-Platform B-Tree Disk File
SYNCHRONIZATION / RUNTIME:Local Embedded Engine (Zero Network)
$ sqlite3 data.db .dump > archive.sql
VCS & Core Tier 1 • Canonical

Fossil SCM

Engineered by the creator of SQLite. Packages version control, tickets, bug tracking, and wiki documentation into one durable SQLite file that runs an instant local web UI that works offline.

STORAGE SUBSTRATE:Single Standalone SQLite Database File
SYNCHRONIZATION / RUNTIME:Peer-to-peer HTTP/SSH sync
$ fossil ui repository.fossil
Tasks & Finance Tier 1 • Canonical

Taskwarrior

Command-line task manager with deterministic date and priority grammars and a complete JSON export, kept separate from long-form notes.

STORAGE SUBSTRATE:Local task database with open JSON export
SYNCHRONIZATION / RUNTIME:Local hooks / sync server / Syncthing
$ task export > commitments.json
Tasks & Finance Tier 1 • Canonical

Todo.txt

The simplest possible task format: one line per task, with priority, project and context markers readable by any text tool.

STORAGE SUBSTRATE:Single plain-text file, one task per line
SYNCHRONIZATION / RUNTIME:Git / Syncthing
$ grep '^(A)' todo.txt
Tasks & Finance Tier 1 • Canonical

Beancount / hledger

Plain-Text Accounting (PTA). Enforces strict double-entry mathematical invariants locally without bank scraping breakages or recurring cloud subscriptions.

STORAGE SUBSTRATE:UTF-8 Plain-Text Double-Entry Ledgers
SYNCHRONIZATION / RUNTIME:Git Version Control / File Sync
$ bean-query ledger.beancount 'SELECT account, sum(position)'
Tasks & Finance Tier 2 • Sovereign Core

Actual Budget

Local-first zero-based budgeting. Runs entirely offline against a local SQLite database and synchronizes across devices via verifiable Hybrid Logical Clock CRDT messages.

STORAGE SUBSTRATE:Client-Side SQLite + Merkle CRDTs
SYNCHRONIZATION / RUNTIME:Self-Hosted Docker Sync with E2EE
$ Export standard SQLite / CSV archive
Knowledge & Office Tier 2 • Sovereign Core

Obsidian

Notes stay as standard UTF-8 Markdown files in a local folder you can edit in Vim, VS Code or bash. The app is closed-source (free for personal use), so the open files, not the application, are what earn the entry.

STORAGE SUBSTRATE:Local Directory of Plain Markdown (.md)
SYNCHRONIZATION / RUNTIME:Decoupled (Syncthing, Git, or paid first-party sync)
$ cp -r ~/Vault /backup/plain-markdown/
Knowledge & Office Tier 2 • Sovereign Core

Logseq

Open-source outliner that stores notes as plain Markdown or Org files in a local folder, so the same 'File Over App' guarantee holds without a proprietary application.

STORAGE SUBSTRATE:Local Directory of Markdown / Org Files
SYNCHRONIZATION / RUNTIME:Decoupled (Syncthing or Git)
$ cp -r ~/logseq-graph /backup/plain-markdown/
Knowledge & Office Tier 1 • Canonical

Emacs Org-Mode

The grand-ancestor of sovereign personal computing. Unifies structured prose, deterministic agendas, tables, and literate programming inside immortal plain text.

STORAGE SUBSTRATE:Plain-Text .org Outlines
SYNCHRONIZATION / RUNTIME:Git / rsync / Syncthing
$ emacs --batch file.org -f org-html-export-to-html
Knowledge & Office Tier 1 • Canonical

Typst

Deterministic document typesetting from plain text that recompiles multi-page documents in milliseconds, offline.

STORAGE SUBSTRATE:Plain-Text Markup (.typ)
SYNCHRONIZATION / RUNTIME:Single zero-dependency native binary
$ typst compile manuscript.typ output.pdf
Knowledge & Office Tier 1 • Canonical

Hugo

Static site generator that compiles a whole site from plain files in milliseconds, offline. This site is built with it.

STORAGE SUBSTRATE:Plain-Text Markdown (.md) + TOML/YAML front matter
SYNCHRONIZATION / RUNTIME:Single zero-dependency native binary
$ hugo --minify
Knowledge & Office Tier 2 • Sovereign Core

Paperless-ngx

Enforces the Archive Invariant: never locks or mutates original documents inside a proprietary blob. Stores untouched PDFs on disk alongside archival PDF/A files. Running it normally needs Docker plus a database and other services, which is why it sits in Tier 2.

STORAGE SUBSTRATE:Pristine Original PDFs + PDF/A + SQLite
SYNCHRONIZATION / RUNTIME:Self-Hosted Container / Local Filesystem
$ document_exporter ../export --no-progress-bar
Knowledge & Office Tier 2 • Sovereign Core

LibreOffice (ODF)

Full desktop office suite running 100% offline. Native files are standard zip containers holding documented XML (`content.xml`) extractable with basic POSIX unzip. The suite is large and slow to start, so it does not clearly pass the 100ms test.

STORAGE SUBSTRATE:ISO/IEC 26300 OpenDocument XML (.odt/.ods)
SYNCHRONIZATION / RUNTIME:Local Filesystem
$ unzip -p document.odt content.xml | xmllint --format -
Engineering & CAD Tier 1 • Canonical

OpenSCAD

Code-first 3D solid modeling. Eliminates the non-deterministic Topological Naming Problem of GUI CAD kernels; identical script inputs yield identical meshes.

STORAGE SUBSTRATE:Programmatic CSG Plain-Text Scripts (.scad)
SYNCHRONIZATION / RUNTIME:Git Version Control
$ openscad -o part.stl model.scad
Engineering & CAD Tier 1 • Canonical

KiCad

Electronic schematic capture and PCB design suite where every net, footprint, and trace is stored in human-readable S-expressions with zero cloud licensing.

STORAGE SUBSTRATE:Plain-Text S-Expressions (.kicad_sch/.kicad_pcb)
SYNCHRONIZATION / RUNTIME:Git / Local Vendor Libraries
$ kicad-cli pcb export gerbers board.kicad_pcb
Engineering & CAD Tier 1 • Canonical

NGSPICE

Deterministic analog and mixed-signal circuit simulator solving differential equations directly from human-readable netlists without network dependencies.

STORAGE SUBSTRATE:Plain-Text SPICE Netlists (.cir / .sp)
SYNCHRONIZATION / RUNTIME:Standalone POSIX CLI
$ ngspice -b -r rawfile.raw circuit.cir
Media & Creative Tier 2 • Sovereign Core

REAPER

Professional Digital Audio Workstation with no cloud accounts and plain-text project files parseable with standard text tools. The application itself is closed-source and paid, which keeps it out of Tier 1.

STORAGE SUBSTRATE:Human-Readable ASCII Project Files (.RPP)
SYNCHRONIZATION / RUNTIME:Portable local install (~15MB), proprietary licence
$ grep -E 'TRACK|VOLPAN' session.RPP
Media & Creative Tier 1 • Canonical

Darktable

Non-destructive raw photography workflow. Never alters original sensor data; all exposure curves and crops reside in sibling XML sidecar files.

STORAGE SUBSTRATE:Immutable RAW + ISO Standard .xmp Sidecars
SYNCHRONIZATION / RUNTIME:Local Disk Hierarchy
$ darktable-cli image.RAW image.RAW.xmp export.jpg
OS & Infra Tier 1 • Canonical

Pass

Secrets live as individual GPG-encrypted files in a directory you control, with no third-party vault server.

STORAGE SUBSTRATE:GPG-encrypted files in a plain directory
SYNCHRONIZATION / RUNTIME:Git / Syncthing (no commercial cloud)
$ gpg -d ~/.password-store/infra/root.gpg
OS & Infra Tier 2 • Sovereign Core

KeePassXC

Open-source password manager with a documented, encrypted vault file on your disk. The vault is binary, not plain text, so it ranks below Pass.

STORAGE SUBSTRATE:Open KDBX vault (binary, documented format)
SYNCHRONIZATION / RUNTIME:Git / Syncthing (no commercial cloud)
$ keepassxc-cli export --format csv vault.kdbx
OS & Infra Tier 1 • Canonical

Syncthing

The canonical decoupled synchronization layer. Replicates folders across devices with cryptographic device IDs and explicit conflict file preservation.

STORAGE SUBSTRATE:Direct Peer-to-Peer Block Exchange (BEP)
SYNCHRONIZATION / RUNTIME:End-to-End TLS over LAN / Relay
$ syncthing cli show system
OS & Infra Tier 1 • Canonical

NixOS / GNU Guix

While mainstream OS platforms mutate global state imperatively, NixOS/Guix treat the entire operating system as a deterministic, rollback-capable function of plain text.

STORAGE SUBSTRATE:Declarative Plain-Text System Configs
SYNCHRONIZATION / RUNTIME:Reproducible Content-Addressed Store
$ nixos-rebuild build --flake .#workstation
OS & Infra Tier 2 • Sovereign Core

OpenBSD

Small, auditable operating system whose configuration lives in plain-text files. It is imperative rather than declarative, but every setting is inspectable and diffable.

STORAGE SUBSTRATE:Plain-text configuration files in /etc
SYNCHRONIZATION / RUNTIME:Local filesystem / Git
$ tar czf etc-backup.tgz /etc
