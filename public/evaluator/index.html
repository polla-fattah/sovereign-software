## Sovereign Architecture Verification Gates
Every pull request or architectural change must pass the seven engineering gates:

- [ ] **1. The Offline Test (Air-Gap)** Core CRUD, compilation, and search operate 100% offline with the network interface physically disabled.
- [ ] **2. The 100ms Test (Responsiveness)** Routine local interactions and incremental saves provide perceptual feedback in under 100ms on baseline hardware.
- [ ] **3. The Longevity Test (50-Year Survivability)** Data is stored in or natively exports to documented, self-describing plain text, open XML, or archival SQLite.
- [ ] **4. The Responsibility Test (Anti-Monolith)** Maintains a bounded domain focus and interoperates via URIs, CLI pipes, or sidecars rather than duplicating unrelated suites.
- [ ] **5. The Dependency Test (Zero Lock-In)** Zero mandatory cloud subscriptions, zero undisclosed telemetry, and no fragile transitive dependency trees.
- [ ] **6. The Predictability Test (Determinism)** State transitions, conflict resolutions and any AI assistance follow deterministic rules and explicit user validation.
- [ ] **7. The Recovery & Security Test (Custody)** Provides transparent conflict resolution (CRDTs/branching) and frictionless, verifiable local backups.
