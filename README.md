# Sovereign Personal Software

A manifesto for software that people own, and the tools that go with it: an index of examples, an interactive seven-gate evaluator, and practical ways to leave cloud services. The site is built with [Hugo](https://gohugo.io/) and loads nothing from third parties.

**Live site:** https://polla.dev/sovereign-software/

## What is on the site

| Page | Source | What it is |
| --- | --- | --- |
| Home (`/`) | `layouts/index.html` | The full manifesto as a designed page |
| Reading edition (`/read/`) | `content/read.md` | The same text for reading and printing, with footnote citations. Also published as a downloadable Markdown file |
| The Manifesto (`/manifesto/`) | `content/manifesto.md` | A one-page summary |
| Sovereign Index (`/directory/`) | `data/directory.json` | Example tools with editorial tier ratings |
| 7-Gate Evaluator (`/evaluator/`) | `data/gates.json` | Interactive scorer, plus a pull request checklist generated from the same gates |
| Escape Hatches (`/escape-hatches/`) | `data/escape.json` | Short recipes for moving data out of cloud services |

The tiers in the Index and the example scores in the Evaluator are editorial judgments, not formal audits.

## Editing content

- **The manifesto text lives in two places.** `content/read.md` is the source for the reading edition and the downloadable file. The home page (`layouts/index.html`) is hand-written HTML with the same text, so when you change the manifesto, change both. Footnote numbers in `read.md` renumber themselves; the source list on the home page is numbered by hand.
- **The seven gates** are defined once in `data/gates.json` and feed the Evaluator and the checklist. The gate wording inside the manifesto text (Section 06) is separate and must be kept consistent by hand.
- **Tools and recipes** are plain JSON in `data/`. Add or edit an entry and rebuild; no template changes are needed.
- Page intros are the Markdown bodies of `content/directory.md`, `content/evaluator.md` and `content/escape-hatches.md`.

## Running locally

Requires Hugo v0.166 or newer.

```bash
hugo server
```

Open http://localhost:1313/. `hugo server` reads `config/development/hugo.toml`, which sets `baseURL` for local use. Restart the server after changing any config file.

To build the site into `public/`:

```bash
hugo --gc --minify
```

## Styles, fonts and scripts

Nothing is loaded from a CDN or a third-party font service.

- **Fonts** are in `static/fonts/` and declared in `static/css/fonts.css`: Inter and JetBrains Mono (SIL OFL 1.1) and General Sans (Fontshare, ITF Free Font License).
- **CSS** is generated by the [Tailwind CSS v3 standalone CLI](https://github.com/tailwindlabs/tailwindcss/releases/tag/v3.4.17) into `static/css/tailwind.css`, which is committed. Rebuild it whenever you add or change utility classes in layouts, content or `static/js/`:

  ```bash
  ./tools/tailwindcss -c tailwind.config.js -i tailwind.input.css -o static/css/tailwind.css --minify
  ```

  The CLI binary is not committed (`tools/` is git-ignored). Download the build for your platform from the release page above (for example `tailwindcss-windows-x64.exe`, `tailwindcss-macos-arm64` or `tailwindcss-linux-x64`), save it in `tools/` as `tailwindcss` (`tailwindcss.exe` on Windows), and check it against `sha256sums.txt` from the same release.
- **JavaScript** is limited to `static/js/sovereign.js`, loaded only on the Index and Evaluator pages (pages opt in with `js = true` in their front matter). Every other page ships no JavaScript.

## Publishing

The site deploys to GitHub Pages from `main` through `.github/workflows/pages.yml`. `public/` is generated output and is git-ignored.

One-time setup: open **Settings → Pages** in the repository and set **Source** to **GitHub Actions**.
